TheCompressor · 使用说明
====================

作用
----
把视频改用显卡自带的硬件编码器重新压缩。程序启动时会读取本机显卡，
NVIDIA 自动用 NVENC，Intel 核显/Arc 自动用 QSV；默认 H.264，可选 HEVC(H.265)，
质量目标等效 libx265 -crf 同数值。硬件编码器没有 CRF，NVIDIA 用 -rc vbr -cq N
（恒定质量 VBR），Intel 用 -global_quality N，实测与 x265 crf 的码率、SSIM
基本齐平，速度快 5～15 倍。
启动后约半秒会做一次编码器自检，日志里写“编码器自检通过：显卡名 · NVENC/QSV”；
如果自检没过（驱动不支持或显卡被禁用），会自动换到另一家可用的硬件编码器。

用法
----
1. 双击 TheCompressor.exe（首次启动自解压内置 ffmpeg，约需 2～4 秒）。
2. 把视频拖进虚线框（支持多文件，也支持直接拖文件夹，递归收集视频）；
   也可以点虚线框用文件对话框选择。
3. 列表显示时长、大小和状态。
4. 点“开始转码”。进度条显示百分比、已转/总时长、倍速、剩余时间；
   下方日志实时输出每个文件的编码信息。
5. 完成/失败在“状态”列标出，成功时显示体积变化（如 完成 省63%）。

窗口与布局
----------
· 初始窗口按 DPI 归一化换算：以 225% 缩放下的 2000×1200 为基准，先折回
  100% 逻辑尺寸，再乘目标机器的实际缩放倍数；在 100% 的 1080p 屏上会自动
  缩小到约 888×533，不会接近全屏。
· 窗口尺寸自动限制在屏幕工作区内并居中；最小窗口同样随缩放换算，保证标签、
  按钮、下拉框在最小尺寸下完整显示、不被裁切；列表和日志区可滚动压缩。
· 窗口放大时，文件列表和日志区按比例拉伸；文件名列随窗口伸缩，其余列固定。
· 设置项分四行排布，窄窗口下不会横向裁切。

输出
----
输出文件放在原视频同级目录，文件名追加 _cq23 后缀（CQ 值随设置变化），
例如 D:\视频\旅行.mp4 → D:\视频\旅行_cq23.mp4；重名自动加 (2)、(3)。

参数
----
质量 CQ    滑块 16～30，默认 23。左滑（数值小）画质好、体积大；右滑（数值大）
           画质差、体积小。滑块下方实时显示画质档位与体积档位，头部给出评价：
           16 极致画质；17～18 高画质；19～20 偏画质；21～25 均衡推荐；
           26～27 小体积；28～30 最小体积。
编码器     默认 H.264（兼容性最好）；可选 HEVC(H.265)，同画质下体积约小 30%。
           Intel QSV 的 H.264 不支持 10bit，遇到 10bit 素材会自动按 8bit 输出，
           HEVC 则保留 10bit。
编码速度   NVIDIA：p7 最慢质量最好 / p6 推荐 / p5 平衡 / p4 快速；
           Intel：veryslow / slow / medium / fast，对应同样的四档。
输出容器   mp4（兼容性最好） / mkv（保留全部音轨和字幕）。
音频       复制（不重编码；MP4 不支持的编码自动转 AAC 192k） / 强制 AAC 192k。
GPU 解码   开启后解码交给显卡，4K 素材更省 CPU；不适用时自动回退 CPU 解码重试。
输出分辨率 默认勾选“保持原分辨率”，此时不改变尺寸；取消勾选后可在下拉框选择
           4K(2160p)、2K(1440p)、1080p、720p、540p、360p、270p。高度为所选
           档位，宽度按原视频长宽比自动计算并取偶数，竖屏视频同样适用；
           缩放使用 lanczos 算法，日志会显示实际输出尺寸。

注意
----
· 需要 NVIDIA 或 Intel 显卡，且显卡驱动为近两年的版本（Intel 建议 31.x 以上）。
  只支持 NVIDIA 和 Intel，AMD 显卡暂时不在支持范围内。
· HDR 素材保留 10bit 和色彩标记，但不做 HDR→SDR 色调映射，SDR 屏上可能偏灰。
· MP4 容器不写入字幕轨；保留字幕请选 MKV。
· 输出不删除原文件，请自行确认后再清理。
· 设置记忆在 %LOCALAPPDATA%\TheCompressor\config.json（旧版设置会自动迁移）。
· exe 未签名，火绒/Defender 首次运行可能弹提示。
